# Portfolio — Veille technologique

Vocabulaire de la section Veille du portfolio (page principale et archive), alimentée par le projet VeilleFacile.

## Langage

**Domaine** :
Le sujet unique de toute la section Veille (aujourd'hui : l'IA générative appliquée à la productivité).
_À éviter_ : Thème, Sujet (au sens large)

**Méthode de veille** :
La façon dont la veille sur le Domaine est menée : sources suivies, outils, processus. Présentée uniquement sur la page principale.
_À éviter_ : Process, workflow

**Source** :
Une ressource capturée dans VeilleFacile, quel que soit son format (vidéo, dépôt, modèle, article de blog).
_À éviter_ : Article, lien, entrée

**Expérimentation** :
Une Source accompagnée de mon propre essai de la nouveauté qu'elle présente (texte et démonstration). Elle offre deux vues : la Source et l'Expérimentation.
_À éviter_ : Technologie, nouveauté, démo

**Démonstration** :
Le support visuel d'une Expérimentation : galerie d'images, vidéo ou page HTML autonome.

**Format** :
La nature d'une Source, déduite de son site d'origine : Vidéo, Code, Modèle ou Article.
_À éviter_ : Type

**Sujet** :
Un mot-clé de VeilleFacile utilisé comme filtre sur les Sources.
_À éviter_ : Catégorie, tag, thème

**Source privée** :
Une Source portant le mot-clé `privé`, jamais affichée sur le portfolio.

## Projets

**Projet** :
Une réalisation présentée sur le portfolio, avec une carte dans la liste des projets et une page détaillée.
_À éviter_ : Réalisation, travail

**Bloc** :
Un élément de contenu d'une page Projet (texte, features, code, images, note…). Une page Projet est une suite ordonnée de Blocs.
_À éviter_ : Section, composant, widget

## Administration

**Admin** :
L'interface protégée qui sert à créer, modifier et supprimer les Projets et les Expérimentations depuis le site en ligne. Chaque enregistrement est publié au déploiement suivant.
_À éviter_ : Éditeur, back-office, CMS

**Brouillon** :
Un Projet ou une Expérimentation pas encore publié : invisible sur le site public, visible seulement depuis l'Admin.
_À éviter_ : Caché, privé (réservé aux Sources privées)
